WORKFLOW

What the skill makes explicit

Every stage produces inspectable evidence and preserves the boundary between a diagnostic signal and a release claim.

  1. 01

    Resolve

    Pin the checkpoint revision and choose smoke, quick, core, or release scope.

  2. 02

    Preflight

    Check disk, inodes, RAM, VRAM, caches, running processes, and context feasibility before downloading.

  3. 03

    Execute

    Run the official task registry through isolated harness environments with recorded protocols.

  4. 04

    Resume

    Use manifests and raw artifacts to continue interrupted batches without duplicating completed work.

  5. 05

    Normalize

    Attach model, task, language, prompt, limit, harness, provenance, and limitation metadata.

  6. 06

    Publish

    Validate results and update the dashboard only after the evidence is complete and publication is authorized.
